# 🎲 Monty Hall Simulator (React + Vite + Mantine)

Interactive Monty Hall problem demo with manual play and Monte Carlo simulation. Built with React, Vite, Mantine UI, Recharts, Framer Motion, and Zustand.

## Features
- Play Mode: choose doors, host reveals, switch or stay, animated doors, confetti on win
- Simulation Mode: run thousands of trials, progress bar, bar chart comparison
- Stats & Insights: live win rates, convergence illustration, explanation
- Violet theme, rounded cards, dark/light toggle

## Tech
- React + TypeScript + Vite
- Mantine UI + Notifications
- Recharts for charts
- Framer Motion for animations
- Zustand for simple global state

## Run locally
```bash
pnpm i # or npm install / yarn
pnpm dev # or npm run dev / yarn dev
```

## Build
```bash
pnpm build
pnpm preview
```

## Deploy to Vercel
- Import the repo in Vercel
- Framework preset: Vite
- Build command: `vite build`
- Output: `dist`
